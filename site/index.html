ArknightsNexus

명일방주 오퍼레이터 정보, 아이템 정보, 오퍼레이터 육성 계획을 돕는 비공식 팬 메이드 앱입니다. Windows와 Android에서 동작합니다.

다운로드 (GitHub Releases) 소스 코드

주요 기능

  • 오퍼레이터

    스킬, 재능, 잠재, 모듈, 공격 범위와 정예화·스킬·모듈 육성 재료를 확인합니다.

  • 아이템

    아이템 정보, 획득 스테이지, 기반시설 제작 공식과 Penguin Stats 드롭 통계를 봅니다.

  • 육성 계획

    목표 단계를 정하면 필요한 재료를 합산하고, 보유 수량과 비교해 부족분을 보여 줍니다.

  • 5개 서버

    CN, KR, JP, TW, EN 서버 데이터를 지원하며, 선택한 서버의 언어로 화면이 표시됩니다.

게임 데이터

이 사이트는 앱이 내려받는 서버별 게임 데이터 스냅샷(data/manifest.json)도 제공합니다. 공개된 ArknightsAssets/ArknightsGamedata 테이블을 GitHub Actions에서 앱과 같은 코드로 정리해 올리며, 이 사이트에 접속할 수 없으면 앱은 원본 테이블을 직접 받아 처리합니다.

English

ArknightsNexus is an unofficial, fan-made Windows and Android app for Arknights players: operator details, item data, and operator promotion planning, for the CN, KR, JP, TW and EN servers. Download it from GitHub Releases. This site also hosts the per-region game data snapshots the app downloads, built from the public ArknightsGamedata tables by GitHub Actions. See the privacy policy.
