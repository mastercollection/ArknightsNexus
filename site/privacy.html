개인정보처리방침

시행일: 2026년 10월 15일

English version below

ArknightsNexus(이하 "앱")는 명일방주 플레이어를 위한 비공식 팬 메이드 앱입니다. 앱에는 회원 가입이나 로그인이 없고, 개발자가 운영하는 서버도 없습니다. 이 방침은 앱이 어떤 데이터를 어디에 저장하고, 어떤 외부 서비스와 통신하는지 설명합니다.

1. 기기에 저장되는 데이터

앱이 다루는 데이터는 모두 사용자의 기기 안에만 저장되며, 개발자에게 전송되지 않습니다.

데이터내용
user_data.json육성 계획(선택한 오퍼레이터와 목표 단계), 즐겨찾기, 아이템 보유 수량
서버별 데이터 캐시내려받은 게임 데이터(오퍼레이터, 아이템, 스테이지 등)
이미지 캐시내려받은 오퍼레이터·아이템 이미지
로그오류와 데이터 동기화 기록(문제 해결용)

설정에서 사용자 데이터를 직접 고른 위치에 파일로 내보내거나 가져올 수 있고, 로그를 내보낼 수 있습니다. 이렇게 만든 파일을 다른 곳에 공유할지는 사용자가 결정합니다. Android에서는 앱을 삭제하면 위 데이터도 삭제됩니다. Windows에서는 %APPDATA%와 %LOCALAPPDATA% 아래의 앱 폴더를 지우면 삭제됩니다. 내보낸 파일은 사용자가 직접 관리합니다.

2. 외부 서비스와의 통신

앱은 게임 데이터와 이미지를 받기 위해 다음 공개 주소에 접속합니다. 이 요청에는 사용자 데이터가 포함되지 않습니다. 다만 일반적인 인터넷 통신과 마찬가지로 각 서비스는 IP 주소, 요청 시각, 앱 이름이 담긴 User-Agent 등을 자체 정책에 따라 기록할 수 있습니다.

  • GitHub (raw.githubusercontent.com): ArknightsAssets/ArknightsGamedata의 게임 데이터 테이블, fexli/ArknightsResource의 이미지
  • GitHub Pages (mastercollection.github.io): 이 사이트에서 제공하는 정리된 게임 데이터 스냅샷
  • Penguin Stats (penguin-stats.io): 아이템 드롭 통계

관련 정책: GitHub 개인정보 처리방침, Penguin Stats.

3. 수집하지 않는 것

  • 분석(애널리틱스), 사용 통계, 크래시 리포트 도구를 사용하지 않습니다.
  • 광고를 표시하지 않으며 광고 식별자를 사용하지 않습니다.
  • 개발자가 운영하는 서버가 없고, 개인정보를 판매하거나 제3자에게 제공하지 않습니다.

4. Google Drive 동기화 (선택 기능, 제공 예정)

앞으로 제공될 Google Drive 동기화는 사용자가 직접 켜는 경우에만 동작합니다. 사용하도록 설정하면:

  • Google 계정으로 로그인하고, 앱 전용 데이터 폴더 권한(https://www.googleapis.com/auth/drive.appdata)만 요청합니다.
  • 앱 데이터(위 user_data.json의 내용: 육성 계획, 즐겨찾기, 아이템 보유 수량)를 사용자의 Google Drive appDataFolder에만 저장합니다. 이 폴더는 이 앱만 접근할 수 있으며, Drive의 다른 파일은 읽거나 수정하지 않습니다.
  • Drive에 저장한 데이터는 사용자의 기기 간 동기화에만 사용하며, 개발자를 포함한 누구에게도 전송하지 않습니다.
  • 설정에서 언제든 연결을 해제하고 Drive에 저장된 앱 데이터를 삭제할 수 있습니다. Google 계정의 서드파티 액세스 설정에서 앱 권한을 철회할 수도 있습니다.

ArknightsNexus가 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 행위는 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 아동의 개인정보

앱은 누구의 개인정보도 수집하지 않으며, 아동의 개인정보도 마찬가지입니다.

6. 방침의 변경

이 방침이 바뀌면 이 페이지를 수정하고 시행일을 갱신합니다. 변경 내역은 GitHub 저장소에서 확인할 수 있습니다.

7. 문의

개인정보와 관련된 문의는 GitHub Issues로 남겨 주세요.

Privacy Policy

Effective date: October 15, 2026

ArknightsNexus ("the app") is an unofficial, fan-made app for Arknights players. It has no sign-up or login, and the developer runs no servers. This policy explains what data the app stores, where, and which external services it contacts.

1. Data stored on your device

Everything the app works with is stored only on your device and is never sent to the developer.

DataContents
user_data.jsonPromotion plans (selected operators and target levels), favorites, owned item counts
Region data cacheDownloaded game data (operators, items, stages, etc.)
Image cacheDownloaded operator and item images
LogsError and data sync records, for troubleshooting

From the settings you can export or import your user data as a file at a location you choose, and export the log. Whether to share such files is up to you. On Android, uninstalling the app removes this data. On Windows, delete the app's folders under %APPDATA% and %LOCALAPPDATA%. Exported files are yours to manage.

2. External services

To download game data and images, the app connects to the public addresses below. These requests contain none of your user data. As with any internet request, each service may record your IP address, the request time and the User-Agent (which names the app) under its own policy.

  • GitHub (raw.githubusercontent.com): game data tables from ArknightsAssets/ArknightsGamedata and images from fexli/ArknightsResource
  • GitHub Pages (mastercollection.github.io): the pre-processed game data snapshots published on this site
  • Penguin Stats (penguin-stats.io): item drop statistics

See the GitHub General Privacy Statement and Penguin Stats.

3. What the app does not do

  • No analytics, usage statistics or crash reporting tools.
  • No ads and no advertising identifiers.
  • No developer-run servers; personal data is never sold or shared with third parties.

4. Google Drive sync (optional, upcoming)

The upcoming Google Drive sync only works if you enable it. If you enable it:

  • You sign in with your Google account, and the app requests only the app data folder scope (https://www.googleapis.com/auth/drive.appdata).
  • Your app data (the contents of user_data.json above: promotion plans, favorites, owned item counts) is stored only in the appDataFolder of your Google Drive. Only this app can access that folder; the app does not read or change any other Drive files.
  • Data stored in Drive is used only to sync your own devices and is not sent to anyone, including the developer.
  • You can disconnect at any time and delete the app data stored in Drive from the settings. You can also revoke the app's access in your Google Account third-party access settings.

ArknightsNexus's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Children's privacy

The app collects no personal information from anyone, including children.

6. Changes

If this policy changes, this page is updated along with the effective date. The change history is visible in the GitHub repository.

7. Contact

For privacy questions, please open an issue on GitHub Issues.
